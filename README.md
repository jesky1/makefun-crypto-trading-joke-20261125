One funny line about crypto and trading life, written by a small deterministic Node program for make.fun's "Laugh Track: The Crypto Trading Joke" bounty ($2 in USDC, top 10). The line: a trader buys the dip, the dip buys a shovel, and the portfolio becomes a museum of coins he swore he'd sell at the top.

## Run it

```sh
node main.ts
```

It validates the line (1–200 characters, one line, no trailing whitespace, no control or invisible characters) and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

## Tests

```sh
node --test test.mjs test-neg.mjs
```
